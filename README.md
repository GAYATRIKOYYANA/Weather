# 🌦️ Weather App

A responsive Weather Application built using **HTML, CSS, and JavaScript** with the **OpenWeatherMap API**. It provides real-time weather information for different cities with dynamic backgrounds that change according to weather conditions.

## 🚀 Link

[https://weather3.ccbp.tech/](https://weather3.ccbp.tech/)

## ✨ Features

- Search weather by city name.
- Display real-time temperature in Celsius.
- Show current weather conditions and descriptions.
- Display humidity and wind speed.
- Show sunrise and sunset times.
- Display the city's local time.
- Dynamic weather-based background images.
- Weather icons based on current conditions.
- Responsive design for desktop and mobile devices.
- Error handling for invalid city names.

## 🛠️ Technologies Used

- HTML5 – Application structure.
- CSS3 – Styling, responsive design, and backgrounds.
- JavaScript – Application logic and API integration.
- OpenWeatherMap API – Real-time weather data.

## ⚙️ How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/GAYATRIKOYYANA/Weather.git
```

2. Open the project folder:

```bash
cd Weather
```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🔑 API Configuration

This project uses the OpenWeatherMap Current Weather API.

1. Create an account at https://openweathermap.org/
2. Generate an API key.
3. Add your API key in `index.js`:

```javascript
const API_KEY = 'YOUR_API_KEY';
```

**Important:** Do not expose your API key in a public repository. For a production application, use a backend to protect your API key.

## 🌈 Dynamic Weather Backgrounds

The application changes its background according to the weather:

- ☀️ Sunny / Clear
- 🌧️ Rainy
- ❄️ Snowy
- ☁️ Cloudy
- 🌫️ Foggy / Misty
- 🌙 Night
